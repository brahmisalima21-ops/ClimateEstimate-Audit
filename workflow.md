# Research workflow
1. Search scholarly databases, publisher pages, preprint repositories and official regulators.
2. Record each candidate; deduplicate by DOI/title.
3. Verify metadata at source and full text where possible.
4. Extract climate exposure, outcome, framework, sample, method, and limitations.
5. Classify with the rules in classification_rules.md and note the page or table you used.
6. Run validator and tests; inspect output.
7. Keep reproducible search logs (query/date/database/filters/results/export).
